## 💡 Sobre

Durante este projeto, foram desenvolvidas funções para resolver desafios diversos, como verificar palíndromos, encontrar o maior número em uma lista, codificar e decodificar strings, entre outros.

Essas funções foram validadas com testes automatizados utilizando a biblioteca **Jest**.

## 🛠️ Habilidades desenvolvidas

- Manipulação de arrays e strings em JavaScript
- Escrita de funções puras com responsabilidade única
- Prática de testes automatizados com Jest
- Aplicação de lógica de programação funcional

## 🧪 Tecnologias utilizadas

- JavaScript ES6+
- Node.js
- Jest
